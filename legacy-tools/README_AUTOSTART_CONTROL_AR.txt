SatLink Remote PRO - PRO 2.2.4 AutoStart Control
المطور: مهند سات لنك

الجديد:
1. داخل نافذة SatLinkRelayServer صار اكو أزرار تشغيل تلقائي:
   - Enable Server AutoStart: يخلي SatLinkRelayServer يشتغل ويا بداية Windows وينزل يم الساعة.
   - Enable Agent AutoStart: يخلي برنامج الحاسبة SatLink Remote PRO يشتغل ويا بداية Windows.
   - Enable Both: يفعل الاثنين سوية.

2. إذا ضغطت X على السيرفر، ما ينغلق؛ ينزل يم الساعة.

3. تقدر تلغي التشغيل التلقائي من نفس الأزرار، أو من الملفات:
   REMOVE_RELAY_AUTOSTART.bat
   REMOVE_AGENT_AUTOSTART.bat

طريقة الاستخدام:
1. شغل START_SATLINK_REMOTE.bat
2. من نافذة SatLinkRelayServer اضغط Enable Server AutoStart إذا تريد السيرفر يشتغل تلقائياً.
3. اضغط Enable Agent AutoStart إذا تريد برنامج الحاسبة يشتغل تلقائياً.
4. أعد تشغيل Windows وجرب.

ملاحظة أمان:
استخدم التشغيل التلقائي فقط على حاسبتك أو حاسبة عندك موافقة صريحة عليها. البرنامج يبقى محمي بالـ PIN والـ Owner Token.
