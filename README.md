# SatLink Remote PRO 2.3.0 Neon

تحكم بحاسبة Windows من موبايل Android عبر نفس شبكة الوايفاي، أو من أي مكان عن طريق سيرفر Relay.

**المطور:** مهند سات لنك

## المميزات
- بث شاشة الحاسبة للموبايل بأربع أوضاع سرعة: اقتصادي، متوازن، سريع، Turbo.
- شاشة تحكم كاملة بدون حواف سوداء، ولوحة أزرار عائمة تنخفي وتظهر.
- لمس مباشر أو وضع **Touchpad** يحرك الماوس مثل اللابتوب.
- اختصارات كيبورد (نسخ، لصق، Alt+Tab، مدير المهام…) وكتابة بالعربي.
- أزرار طاقة: قفل، سكون، إعادة تشغيل، إطفاء. كلها تطلب تأكيد.
- مدير ملفات لرفع وتنزيل الملفات بين الموبايل والحاسبة.
- البرنامج يشتغل وحده مع Windows، وحارس يرجّع السيرفر إذا وكف.
- ثيم نيون.

## هيكل المشروع
| الفولدر | المحتوى |
|---|---|
| `windows-agent/` | برنامج الحاسبة (Python: Flask + Tkinter + pyautogui) |
| `server/` | سيرفر Relay للاتصال من أي مكان |
| `android-app/` | تطبيق Android (Java) |
| `legacy-tools/` | أدوات النسخ القديمة |

## التشغيل على الحاسبة
1. ثبّت Python 3.11.
2. شغّل `BUILD_UNIFIED_RELEASE.bat`.
3. شغّل `dist-unified\SatLinkRemotePRO\SatLinkRemotePRO.exe` مرة وحدة. بعدها يشتغل وحده مع Windows.

للتجربة من الكود مباشرة بدون بناء: شغّل `START_SATLINK_REMOTE.bat`.

## بناء تطبيق الموبايل
افتح فولدر `android-app` بـ Android Studio، وبعدها اختار **Build > Build APK(s)**.

## الأمان ⚠️
- غيّر **Master PIN** الافتراضي `1234` من داخل البرنامج.
- غيّر **Owner Token** الافتراضي `SLR-CHANGE-ME-PRO-2026` بملفي `server/server_config.json` و `windows-agent/relay_config.json`، وبإعدادات Relay بالتطبيق.
- لا ترفع التوكن الحقيقي على GitHub.
- البرنامج يظهر للمستخدم، وكل اتصال يحتاج PIN. استخدمه بس على أجهزتك أو أجهزة عندك إذن تتحكم بيها.
