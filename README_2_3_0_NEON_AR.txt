SatLink Remote PRO 2.3.0 Neon
المطور: مهند سات لنك

== الجديد بهذه النسخة ==

[تطبيق الموبايل]
1) شاشة التحكم صارت كاملة:
   - الصورة تملأ شاشة الموبايل بدون حواف سوداء (وضع "ملء شاشة الموبايل").
   - السحب والزوم صار محدود، فما تطلع منطقة سوداء خارج صورة الحاسبة.
   - من تبويب "العرض" تكدر تبدل لـ "عرض الشاشة كاملة" إذا تريد تشوف الشاشة كلها.
2) الأزرار صارت لوحة عائمة فوق الشاشة:
   - مقسمة لتبويبات: الماوس / المفاتيح / اختصارات / العرض / الطاقة.
   - كل الأزرار تظهر بدون سكرول، وعدد الأعمدة يتغير حسب حجم الشاشة.
   - ما تختفي تحت شريط التنقل أو النوتش.
   - زر دائري فوق يمين يخفي/يظهر اللوحة.
3) وضع Touchpad: إصبع واحد يحرك الماوس، نقرة = كلك، إصبعين = Scroll، نقرة بإصبعين = يمين.
   المؤشر يظهر بالصورة.
4) اختصارات: نسخ، لصق، قص، تراجع، تحديد الكل، حفظ، Alt+Tab، Win، سطح المكتب، المستكشف، Alt+F4، مدير المهام، تبديل اللغة.
   ومفاتيح: Enter، Esc، Backspace، Tab، Delete، الأسهم، Home، End، PgUp، PgDn، Space، F5.
5) أزرار الطاقة (مع تأكيد): قفل، سكون، إعادة تشغيل، إطفاء، إلغاء الإطفاء.
   إعادة التشغيل والإطفاء ينتظرون 10 ثواني وتكدر تلغيها.
6) الكتابة بالعربي صارت تشتغل، مع خيار ضغط Enter بعد الكتابة.
7) ثيم نيون جديد لكل الشاشات.

[برنامج الحاسبة]
1) يتفعل التشغيل مع Windows تلقائياً من أول تشغيل للبرنامج.
   (تكدر تطفيه من زر "تشغيل مع Windows" ويبقى مطفي.)
   إذا نقلت فولدر البرنامج، المسار يتصلح تلقائياً.
2) البرنامج يشغل SatLinkRelayServer بنفسه عند بدء Windows.
3) حارس السيرفر: كل 15 ثانية يفحص، وإذا السيرفر أو الاتصال أو Relay وكف يرجعه.
   لإيقاف السيرفر نهائياً اطفي خيار "السيرفر مع البرنامج".
4) Scroll صار حقيقي (كان ضعيف جداً سابقاً).
5) ثيم نيون لنافذة البرنامج ونافذة السيرفر.

== التحديث ==
- الحاسبة: شغل BUILD_UNIFIED_RELEASE.bat، والناتج داخل dist-unified\SatLinkRemotePRO
  شغل SatLinkRemotePRO.exe مرة وحدة، وبعدها يشتغل وحده مع Windows.
  إذا عندك تشغيل تلقائي قديم منفصل للسيرفر، شغل REMOVE_OLD_SEPARATE_AUTOSTART.bat مرة وحدة.
- الموبايل: افتح فولدر android-app بـ Android Studio وسوي Build APK.
  لازم تحدث الحاسبة والموبايل سوية، لأن الأزرار الجديدة تحتاج برنامج الحاسبة الجديد.

== ملاحظة أمان ==
غيّر Master PIN الافتراضي 1234 و Owner Token الافتراضي، خصوصاً بعد إضافة أزرار الإطفاء وإعادة التشغيل.
