SatLink Remote PRO - Windows Agent PRO 2.2.4

الجديد:
- System Tray بجانب الساعة.
- تشغيل تلقائي مع Windows.
- إيقاف قبول الاتصالات بدون إغلاق البرنامج.
- Master PIN لحماية الإعدادات.
- سجل آخر العمليات.

Master PIN الافتراضي أول مرة: 1234
يرجى تغييره من زر "تغيير Master" بعد أول تشغيل.

أهم الملفات:
- run_py311.bat: تشغيل عادي باستخدام Python 3.11.
- run_minimized_py311.bat: تشغيل مصغر بجانب الساعة.
- start_hidden_py311.vbs: تشغيل مخفي/مصغر بدون نافذة CMD.

ملاحظة:
هذه النسخة تظهر للمستخدم وتحتاج PIN، وليست للعمل الخفي أو غير المصرح به.
