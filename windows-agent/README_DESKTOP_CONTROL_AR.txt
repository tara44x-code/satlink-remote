SatLink Remote PRO - Windows Agent PRO 2.2.4

الجديد في برنامج الحاسبة:
- إصدار PRO 2.2.4.
- دعم أوامر إضافية من تطبيق Android:
  mouse_down / mouse_up / scroll / double_click.
- تحسين تصوير الشاشة بإضافة طريقة احتياطية ImageGrab إذا فشل MSS.

التشغيل:
1. شغل run_py311.bat.
2. اضغط تشغيل الاتصال.
3. اترك البرنامج مفتوحاً.
4. من التطبيق اضغط بحث ثم دخول وتحكم.

إذا ظهرت شاشة سوداء:
- تأكد أن الحاسبة ليست على شاشة القفل.
- اسمح لـ Python من Windows Firewall على Private network.
- اضغط إعادة اتصال داخل تطبيق Android.
